# N8N Workflows - Aura Consulting

Repozytorium szablonów i workflow'ów n8n dla automatyzacji procesów biznesowych.

## 📁 Struktura

- `/workflows/` - Pliki JSON z workflow'ami
- `/docs/` - Dokumentacja i instrukcje
- `/credentials/` - Informacje o wymaganych credential'ach (BEZ faktycznych kluczy!)

## 🚀 Jak importować workflow

1. Pobierz plik `.json` z katalogu `/workflows/`
2. W n8n: Menu → **Import from File**
3. Skonfiguruj wymagane credentials
4. Aktywuj workflow
